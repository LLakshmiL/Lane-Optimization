# Lane-Optimization
Designing and implement an interactive dashboard that evaluates the predictability of ocean freight rates across customer-focused and GEODIS-focused trade lanes using the Signal-to-Noise Ratio (SNR) derived from six months of historical freight rate data. The dashboard should measure the stability of freight rates, rank trade lanes by forecastability, distinguish between stable and highly volatile routes, and provide actionable insights to support tender preparation, procurement decisions, pricing strategies, carrier negotiations, and long-term capacity planning. It should include interactive filtering, trend analysis, volatility metrics, SNR rankings, and forecast confidence indicators to enable data-driven decision-making during the tender process.
