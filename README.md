# Lane-Optimization
Not every container trade lane exhibits the same level of pricing predictability. Using six months of historical Ocean freight rate data, the dashboard evaluates each customer-focused and GEODIS-focused lane based on its Signal-to-Noise Ratio (SNR) and historical backtesting performance. Lanes with strong, stable pricing patterns are automatically routed to the simplest and most cost-effective forecasting model that consistently meets the required accuracy. Lanes with high volatility or poor predictive performance are directed to a safe fallback approach, ensuring reliable tender pricing while avoiding unnecessary model complexity.
